Para empaquetar la aplicación CRUD Tkinter
- Path: ubicarse dentro de la carpeta que se desea distribuir
- Comandos: 
    * pip install pyinstaller
    * pyinstaller --noconfirm --onedir --windowed --icon "assets/favicon.ico" --add-data "assets;assets" main.py
    * pyinstaller --noconfirm --onefile --windowed --icon "assets/favicon.ico" --add-data "assets;assets" main.py
- Explicación:
    --windowed (o -w): VITAL. Si no lo pones, cuando el usuario abra tu .exe, se abrirá primero una horrible ventana negra de consola (CMD) detrás de tu interfaz gráfica. Esto oculta la consola.

    --onedir (o -D): Crea una carpeta con tu ejecutable y todas las librerías al lado. (El instructor quizás te enseñe --onefile para meter todo en un solo .exe, pero en programas con bases de datos locales e iconos, --onedir es más estable y rápido al abrir).

    --add-data: Como el archivo .exe se mueve, esto le dice a PyInstaller que se lleve tu carpeta de assets/ (donde está tu icono) al paquete final.
- Consideraciones: Se debe indicar en settings si se está ejecutando un script VScode o desde un ejecutable .exe

import sys
from pathlib import Path

# 1. CONCIENCIA DE ENTORNO: ¿Soy un script o soy un .exe?
if getattr(sys, 'frozen', False):
    # --- MODO EJECUTABLE (PRODUCCIÓN) ---
    
    # Directorio donde vive el .exe (Perfecto para crear la BD y que el usuario la vea)
    EXEC_DIR = Path(sys.executable).parent
    
    # Directorio oculto temporal/interno de PyInstaller (Perfecto para leer el ícono)
    BUNDLE_DIR = Path(sys._MEIPASS)
else:
    # --- MODO SCRIPT (DESARROLLO EN VS CODE) ---
    EXEC_DIR = Path(__file__).resolve().parent.parent
    BUNDLE_DIR = EXEC_DIR

# 2. RESOLUCIÓN DE RUTAS SEPARADAS
ASSETS       = BUNDLE_DIR / "assets"           # Lee de la carpeta interna
DATA_DIR     = EXEC_DIR / "data"               # Escribe junto al .exe
DB_USUSARIOS = DATA_DIR / "usuarios.db"

# 3. AUTO-REPARACIÓN DE INFRAESTRUCTURA
# Creamos la carpeta de datos junto al .exe si no existe
DATA_DIR.mkdir(parents=True, exist_ok=True)
