Curso de desarrollo web - Listas

En este curso aprenderemos los fundamentos para crear páginas web utilizando HTML, CSS y JavaScript.

Requisitos para seguir el curso

  • Tener instalado VSC
  • Desponer de navegador web
  • Crear carpeta para guardar archivos
  • Practicar los ejemplos de cada video

Ruta recomendada de aprendizaje

  1. Aprender la estructura básica de documento HTML
  2. Practicar con etiquetas de texto
  3. Crear vínculos
    • Internos
    • Externos
  4. Insertar imágenes
  5. Aplicar estilos
